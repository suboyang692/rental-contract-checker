# 🏠 租房合同风险审查助手

一个本地运行的 AI 合同审查工具：上传租房合同 PDF，自动识别押金、违约金、维修责任、转租、提前退租、租金调整等陷阱条款，并生成 Markdown 风险报告。

## 功能

- **PDF 文本提取**：多页解析、空页过滤、页码标记、字符归一化（修复「甲⽅」≠「甲方」的兼容字符问题）
- **规则引擎**：6 类高频陷阱条款（押金退还模糊 / 违约金过高 / 转租惩罚过重 / 维修责任转嫁 / 提前退租惩罚过重 / 租金单方调整），附《民法典》法条依据，官方示范文本 0 误报
- **LLM 结构化抽取**：租金、押金、租期、支付方式、违约金、维修责任、转租、提前退租 8 项关键条款 + 一句话风险总结
- **混合双引擎**：规则兜底高频陷阱 + LLM 泛化理解。实测 LLM 抓到了规则未覆盖的「单方调租」条款，随后固化为第 6 条规则，形成「规则→LLM 补盲区→固化新规则」的迭代闭环
- **Web 界面**：拖拽上传 PDF → 展示风险报告 → 一键下载 Markdown
- **分析历史**：每次分析结果写入 SQLite（`data/history.db`），页面可回看历史报告
- **评测脚本**：基于标注集计算规则引擎的精确率 / 召回率（`eval/`）

## 技术栈

- Python 3.10 · FastAPI · Uvicorn
- pdfplumber（PDF 文本提取）
- 阿里云百炼 Qwen（OpenAI 兼容接口，JSON mode 结构化输出）
- SQLite（标准库 sqlite3，分析历史存储）
- 原生 HTML / CSS / JS（无前端框架）

## 评测

标注集（`eval/annotations.json`）= 3 份样本合同的"预期命中"清单，用于回归验证规则引擎：

```bash
python eval/evaluate.py
```

输出：每份文件的 TP / FP / FN 与精确率 / 召回率。当前样本上 精确率 1.00 / 召回率 1.00。

> 注意：标注集与测试样本同源，属于"回归测试"而非独立评测；独立评测需要更多真实合同数据（大三评测项目方向）。

## 工程细节（面试可讲）

1. **字符归一化**：PDF 提取出的文本会混入 CJK 兼容字符（`甲⽅`/`⺠`），直接关键词匹配会静默失效；用 NFKC + 部首补充区手动映射修复
2. **正则跨行**：PDF 行尾换行会导致规则匹配失败，提取阶段统一去空白
3. **LLM 失败降级**：网络/配额异常时只返回规则结果，接口不崩
4. **安全处理**：上传文件用后即删，API Key 走 `.env` 不提交，历史库不入库
5. **边界识别**：扫描件（无文字层）返回明确提示，不做假结果
6. **规则迭代**：LLM 发现的「单方调租」盲区已固化为 R06 规则，形成双引擎迭代闭环
7. **可评测**：标注集 + 精确率/召回率脚本，量化规则引擎准确度
